EJERCICIO 1 - CATÁLOGO DE PRODUCTOS CON CARRITO

1. Abrir esta carpeta en Visual Studio Code.
2. Abrir la terminal.
3. Ejecutar: npm install
4. Ejecutar: npm run dev
5. Abrir la dirección que muestra Vite.

Cumple con:
- ProductoCard
- ListaProductos
- Carrito
- ItemCarrito
- BuscadorProducto
- useState para carrito y búsqueda
- useEffect + fetch para catálogo
- estados de carga y error
- React Router
- ruta anidada /catalogo/carrito
- formulario/campo de búsqueda controlado
