EXPERIENCIA 5 - NAVEGACIÓN CON REACT ROUTER

1. Abrir esta carpeta en Visual Studio Code.
2. Abrir la terminal.
3. Ejecutar: npm install
4. Ejecutar: npm run dev
5. Abrir la dirección que muestra Vite.

Incluye las vistas Inicio y Tareas y navegación mediante React Router.
La vista Tareas conserva formulario, listado y carga inicial con fetch de las experiencias anteriores.
